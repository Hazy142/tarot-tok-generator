# 🔮 Tarot-Tok Generator

Dein Tool für automatisierten Tarot-Content auf TikTok.

## Setup

1. **Python installiert?** (Hast du wahrscheinlich schon)
2. **Dependencies installieren:**

   ```bash
   pip install streamlit moviepy opencv-python-headless
   ```

## Starten

Navigiere in diesen Ordner und starte die App:

```bash
cd f:\lunarloom_Lab\tarot-tok-generator
streamlit run app.py
```

## Nutzung

1. **Audio hochladen** (MP3, z.B. von ElevenLabs)
2. **Illustration hochladen** (Das Tarot-Bild)
3. **Rahmen hochladen** (PNG mit Transparenz)
4. **Zoom einstellen** (Vibe-Check)
5. **Render klicken** 🚀

Das Video wird generiert und kann direkt heruntergeladen werden.
